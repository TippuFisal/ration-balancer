# Ration Balancer

A single-page web application for balancing animal rations / feed formulation.

## Usage

Open `index.html` in any modern web browser. The app is fully self-contained (all
assets are bundled into the HTML file), so no build step or server is required.

## Files

- `index.html` — the application (bundled, standalone).
- `Ration Balancer v6.html` — original source file (identical copy).
